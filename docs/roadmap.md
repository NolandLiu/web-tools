# Roadmap

## Current MVP

- Public brand and compliance pages use GoDeskHub, `https://tools.godeskhub.com`, and `support@godeskhub.com`.
- Browser-local tools across converters, developer utilities, calculators, and QR Code generation.
- Three-language UI with persisted language choice.
- Local-only popular-tool ranking.
- Three-language static routes for every tool, category, and policy page.
- Per-route build-time SEO, generated Sitemap, custom 404, and Cloudflare Pages deep links.
- AdSense disabled by default.

## Later

- Optional Cloudflare Web Analytics through platform configuration.
- Optional aggregate analytics adapter backed by Cloudflare services after approval.
- Additional tools only when they can share the existing registry and layout.
